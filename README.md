## 📖 About

This portfolio presents a code-editor / terminal-themed UI — sections are laid out like files in a project (`home.tsx`, `about.md`, `skills.json`, `experience.md`, `projects/`, `credentials/`, `contact.sh`) to reflect a developer's actual workspace. It's built to give recruiters and collaborators a fast, clean overview of who I am and what I've built.

**Status:** 🟢 Open to opportunities (Entry-level SWE / AI-ML roles)

## ⚙️ Getting Started (Local Setup)

Clone the repository and run it locally:

```bash
# Clone the repo
git clone https://github.com/aditya262006/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run the development server
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

To build for production:

```bash
npm run build
npm start
```
